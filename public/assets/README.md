# Tammy UI assets

Raster files contain illustration-only content. Interface text, backgrounds, cards,
buttons, borders, shadows, gradients, progress bars, and layout are rendered by
HTML/CSS so they remain responsive and easy to edit.

- `heroes/`: hero illustrations such as `login-hero.png`
- `mascots/`: reusable mascot cutouts such as `tammy-cat.png`
- `products/`: product images used in the shop
- `rewards/`: reward and coupon illustrations
- `banners/`: news and promotion images
- `uploads/`: images uploaded later through the admin interface

`heroes/login-hero-source.png` is retained only for comparison and is not used by
the UI.
