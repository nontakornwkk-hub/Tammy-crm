# แทมมี่อาหารสัตว์ — ระบบสมาชิกและสะสมแต้ม

ต้นแบบ Next.js + TypeScript + Tailwind CSS สำหรับร้านแทมมี่อาหารสัตว์

## หน้าในต้นแบบ

- `/login` — เข้าสู่ระบบ / สมัครสมาชิกด้วยเบอร์โทรศัพท์
- `/admin/points` — ให้แต้มจากยอดซื้อ (ทุก 100 บาท = 1 แต้ม)
- `/admin/members` — สมาชิก ตารางเลื่อนต่อเนื่อง แท็บกรองกลุ่ม และเรียงยอดซื้อ
- `/admin/dashboard` — Dashboard ตัวเลข กราฟ ลูกค้าที่ควรติดตาม และ Top 10
- `/admin/settings` — ตั้งค่าร้าน กฎแต้ม บัญชีพนักงาน และธีมบัตรสมาชิก
- `/admin/rewards` — คูปองและของรางวัล
- `/admin/news` — ข่าวสาร
- `/customer` — ตัวอย่างประสบการณ์ลูกค้าบนมือถือ รวมการตกแต่งบัตร

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

จากนั้นเปิด `http://localhost:3000/login`

หมายเหตุ: ข้อมูลในต้นแบบเป็นข้อมูลจำลองในฝั่ง Client เพื่อสาธิต UX เท่านั้น ยังไม่มีฐานข้อมูลหรือระบบยืนยันตัวตนจริง
